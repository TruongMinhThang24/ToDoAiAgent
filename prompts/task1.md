# 🎯 Tên Task: Checklist đánh dấu chức năng

## 1. Bối cảnh (Context)
- Tính năng này để làm gì?
- Tại sao phải làm nó? (Ví dụ: Để bảo mật hơn, để UI đẹp hơn...)

## 2. Yêu cầu chi tiết (Requirements)
- **Backend:**
  - Cần tạo/sửa API nào? Đường dẫn là gì?
  - Dữ liệu đầu vào (Request), đầu ra (Response) ra sao?
- **Frontend:**
  - Cần tạo UI ở trang nào?
  - Logic xử lý khi người dùng bấm nút là gì?

## 3. Ràng buộc (Constraints)
- Có thư viện bắt buộc nào phải dùng không?
- Cần tuân thủ chuẩn bảo mật nào không?
